About the Data Cube

This interactive explorer integrates glacier geometry, terrain, and climate information for the Upper Rhone region of the Swiss Alps.

RGI Glacier Inventory + Copernicus DEM + ERA5-Land → Harmonized Data Cube → Glacier API

Monthly ERA5-Land temperature and precipitation are aggregated to individual glaciers using glacier-grid intersection area weighting.
