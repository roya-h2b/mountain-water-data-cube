# Mountain Water Data Cube

A reproducible geospatial data pipeline for integrating, harmonizing, and analyzing multi-source cryosphere and mountain hydrology datasets.

## Project Goal

This project demonstrates a reproducible workflow for processing heterogeneous environmental and geospatial datasets relevant to mountain water resources and cryosphere research.

The workflow will integrate multiple data sources, harmonize their spatial and temporal characteristics, organize the processed data using analysis-ready multidimensional formats, and provide tools for scientific analysis and data access.

## Planned Workflow

1. Data acquisition
2. Geospatial preprocessing
3. Spatial and temporal harmonization
4. Multidimensional data cube construction
5. Exploratory cryosphere-hydrology analysis
6. Visualization and mapping
7. Lightweight API for accessing processed data

## Technologies

Python, Git, Xarray, GeoPandas, Rasterio, NetCDF/Zarr, and FastAPI.
